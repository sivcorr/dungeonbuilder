# DungeonBuilder

**DungeonBuilder** is a Minecraft mod for Fabric 1.21.1 designed to make creating, saving, sharing, and placing custom structures easier through an intuitive in-game interface.

The mod provides a simple alternative to complicated building workflows, allowing players to manage their own structure libraries and share creations with servers.

## ✨ Features

- **Structure Selection:** Select areas of the world to turn them into reusable structures.
- **Personal Library:** Save and manage your own structures locally.
- **Structure Exporter:** Send structures from your personal library to a server.
- **Server Library:** Browse structures shared on the server.
- **Preview & Placement:** Preview structures before placing them in the world.
- **Custom Structure Format:** A dedicated format designed to store structure data and metadata.
- **User-Friendly GUI:** Manage structures through clean, accessible in-game menus.

## 🎯 Goals

DungeonBuilder is being developed with a focus on simplicity, compatibility, and multiplayer functionality. It aims to make structure management accessible without relying on external tools.

## 📦 Installation

1. Install Fabric Loader for Minecraft 1.21.1
2. Install Fabric API
3. Download DungeonBuilder from Releases
4. Place the `.jar` file in your `mods` folder
